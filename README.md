## 📌 Overview
The **AI English Writing Assessor** is a production-ready, full-stack educational tool engineered to provide rigorous linguistic feedback for language learners. Powered by the high-speed **Google Gemini 3.6 Flash API**, this application acts as a strict English Linguistics Professor, analyzing user-submitted text to evaluate grammatical accuracy, extract key vocabulary with translations, and provide actionable fluency advice.

Designed with robust server-side API routing and strict JSON output parsing, the platform ensures reliable, fault-tolerant evaluations even under edge-case scenarios.

## ✨ Key Features
*   **🧠 Advanced Grammatical Analysis:** Detects syntax errors, missing punctuation, capitalization issues, and spelling mistakes with detailed reasoning.
*   **📊 CEFR-Level Scoring:** Extrapolates an accurate grammar score (1-10) and maps vocabulary to international CEFR proficiency bands (A1 to C2).
*   **⏱️ Automated Tense Tracking:** Granular analysis of verb tenses (Past, Present, Future) used within the text.
*   **🌍 Multilingual Vocabulary Extraction:** Automatically identifies complex or misspelled words and provides accurate native (Hindi) translations.
*   **🛡️ Strict JSON Fallbacks:** Implements custom regex-based JSON extraction and robust error handling to guarantee UI stability.
